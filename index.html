PDF 解鎖服務（Cloud Run）・選用

只有要自動抓「加密 PDF 對帳單」（例如只出現在 PDF 的定期定額）才需要。只用成交回報信的話可以略過。點各步驟看細節。

這是什麼、要花錢嗎
  • 券商的 PDF 對帳單有密碼，Apps Script 自己打不開，所以需要一個小服務幫忙解鎖並把表格讀出來
  • 服務架在你自己的 Google Cloud，PDF 只在記憶體處理、不存檔，其他人（包含 App 作者）都看不到
  • Google Cloud 需要綁信用卡，但 Cloud Run 有每月免費額度，每天跑一次通常是 0 元；擔心的話可以在「帳單 → 預算與快訊」設一個小額提醒
  • 程式碼公開在 GitHub 的 cloudrun 資料夾，可以自己檢查
1準備 Google Cloud 專案
  1. 用自己的 Google 帳號打開 Google Cloud 主控台・建立專案，第一次會要求同意服務條款
  2. 專案名稱隨意，例如 pdf-unlock → 建立
  3. 左上選單「帳單」→ 連結帳單帳戶（沒有的話依畫面新增信用卡）
2一鍵部署
  1. 按上面的按鈕，會開啟 Google Cloud Shell（網頁版終端機）
  2. 跳出「信任此存放區？」→ 勾選信任 → 確認；要求授權時按「授權」
  3. 依提示選擇剛剛建立的專案；問到區域時選 asia-east1（台灣）
  4. 如果問要不要啟用 API（Cloud Run、Cloud Build 等），輸入 y
  5. 等 3～5 分鐘，最後會顯示一個網址，像 https://pdf-unlock-xxxxx.asia-east1.run.app，複製起來
  6. 用瀏覽器打開這個網址，看到 ok 就代表服務正常
3填回本頁設定
  1. 上面「Gmail 擷取 → Cloud Run 網址」貼上剛剛的網址
  2. 「PDF 郵件標籤」填 Gmail 裡 PDF 對帳單信的標籤（要先在 Gmail 用篩選器自動貼上）
  3. 「基本設定 → 解鎖對帳單密碼」填 PDF 開啟密碼（通常是身分證字號）
  4. 有定期定額的話，「定期定額」區塊填 PDF 裡的中文名稱、股票代碼與開始日
  5. 按右下「儲存」
4測試與疑難排解
  • 「手動執行 → 擷取信件」，PDF 裡的交易會出現在「待確認交易」
  • 第一次呼叫服務要「冷啟動」，可能等 10～30 秒，系統會自動重試
  • 出現「密碼錯誤」：檢查解鎖對帳單密碼（英文字母大小寫也要一樣）
  • 抓不到交易：可能是券商 PDF 格式不同，到「錯誤通知紀錄」看訊息
  • 不想用了：到 Google Cloud 主控台「Cloud Run」刪除服務，並把本頁 Cloud Run 網址清空
